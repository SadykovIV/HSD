## English

Local test candidate, version code 97. DriveDeck companion remains 0.7.0 (356).

- **Android Auto:** Automatic certificate selection uses a verified identity from the installed Android Auto app, including when disabled. Updating Android Auto refreshes the cached identity. Manual selections remain available. A generic authorization refusal no longer implies a clock error.
- **CarLife:** audio and commands can pass waiting video at complete message boundaries. Audio keeps a continuous capture clock through video jitter and native-screen transitions; early pictures are paced on that clock and stale pictures recover without increasing the audio delay. Congestion control now includes the actual age of waiting video.
- Video resume preserves the live music stream and pending speech stop. Diagnostic file writes run outside media and input threads, with a bounded queue and explicit overflow reporting.
- Embedded app hosts keep keyboard focus in the child while their controls remain touchable. Host dialogs temporarily reclaim focus; the policy is shared across supported Android versions.
- Added receiver-side certificate validation and stress checks for PCM continuity, video pacing and large frame bursts. Emulator results do not establish compatibility with an individual factory head unit or its playback buffer.

Validation: 1,527 unit tests passed; all 104 final emulator scenarios passed across Android 10–17, including targeted reruns after test-fixture corrections. CarLife delivered all 2,000 numbered PCM packets on each OS under the configured load. Actual AudioRecord capture was verified on Android 13–17; Android 10–12 exercised the PCM transport without a capture grant.

Update the official Android Auto app, disable it again if required for HSD USB routing, and select **Automatic** under **Android Auto certificates**. An existing manual certificate selection is preserved until you change it.

## Русский

Локальный тестовый кандидат, код версии 97. Модуль DriveDeck остаётся 0.7.0 (356).

- **Android Auto:** режим «Автоматически» использует проверенный сертификат и ключ установленного Android Auto, в том числе отключённого. После обновления Android Auto сохранённые данные обновляются. Ручной выбор сохраняется. Общий отказ авторизации больше не трактуется как ошибка часов.
- **CarLife:** звук и команды проходят перед ожидающим видео между целыми сообщениями. Звук сохраняет непрерывную временную шкалу при колебаниях задержки видео и переходах на штатный экран. Ранние кадры ждут своего времени, устаревшие восстанавливаются без увеличения задержки аудио. Снижение нагрузки учитывает фактический возраст очереди видео.
- Возврат к видео сохраняет живой музыкальный поток и ожидающее завершение подсказки. Запись файла диагностики вынесена из потоков звука и ввода; очередь ограничена, потеря строк при перегрузке отмечается в логе.
- Оболочка вложенного приложения сохраняет фокус ввода в самом приложении; кнопки оболочки остаются доступны для касания. Диалог оболочки временно получает фокус. Правило едино для поддерживаемых версий Android.
- Добавлены проверки сертификата на стороне приёмника и нагрузочные проверки непрерывности PCM, синхронизации и крупных кадров. Результаты эмуляторов не подтверждают работу конкретной заводской магнитолы и её буфера воспроизведения.

Проверка: прошли 1527 модульных тестов и все 104 итоговых сценария на Android 10–17, включая адресные повторы после исправления тестового окружения. CarLife доставил все 2000 пронумерованных PCM-пакетов на каждой ОС при заданной нагрузке. Захват AudioRecord подтверждён на Android 13–17; на Android 10–12 проверен тракт PCM без выданного системой права на захват.

Обновите штатный Android Auto, при необходимости снова отключите его для подключения HSD по USB и выберите **Автоматически** в разделе **Сертификаты Android Auto**. Ранее выбранный вручную сертификат сохраняется, пока вы его не измените.
