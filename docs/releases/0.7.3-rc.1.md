## English

- CarLife keeps audio flowing during map zoom and leaves Bluetooth playback active when the head unit returns from a camera.
- Samsung DeX can start after the phone switches to the head unit’s Wi-Fi. CarLife sends the street name with the turn when the navigation app provides it.
- HSD now offers an English interface. Choose a language under Settings → Maintenance → Language.

## Русский

- В CarLife устранены пропуски звука при масштабировании карты. При возврате с камеры HSD сохраняет воспроизведение по Bluetooth.
- Samsung DeX запускается и после перехода телефона в Wi-Fi магнитолы. CarLife передаёт название улицы вместе с поворотом, если оно есть у навигатора.
- В HSD появился английский интерфейс. Язык можно выбрать в настройках приложения.
