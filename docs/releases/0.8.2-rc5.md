## Русский

Локальный тестовый кандидат, код версии 100. DriveDeck остаётся 0.7.0 (356).

- **Android Auto / DISCOVERY:** телефон передаёт три PNG-иконки HSD размером 32, 64 и 128 пикселей вместе с названием и моделью. В предыдущей версии HSD оставлял эти поля пустыми. Стабильный идентификатор установки сохранён и не зависит от замены сертификата. Формат и порядок обмена общие для USB и TCP.
- После фактической записи запроса журнал сохраняет его размер, размеры иконок и согласованный TLS/шифр. При сбое видны число принятых байтов, завершённые кадры и место незавершённого чтения. Это различает отсутствие ответа, частичный пакет и ошибку обработки TLS. Счётчики включены только на DISCOVERY, без записи содержимого TLS.
- Описание телефона отделено от выбора сертификата. Иконки создаются один раз на процесс, Bluetooth bootstrap получает только идентификатор без работы с графикой; для чтения заголовка переиспользуется один буфер.
- Удалены недостижимая ветка Wi-Fi Android 8/9, старый разбор IP ниже API29, неиспользуемые темы, строки и файлы ресурсов. Минимальная поддерживаемая версия остаётся Android 10. Проверки версий у отдельно запускаемых служебных процессов сохранены.
- Добавлен независимый приёмник на Python/OpenSSL для проверки TLS, protobuf и фрагментации без использования нашего парсера AAP. Строгий тест описания телефона дополнительно проверяет реальные размеры PNG.

В пользовательском журнале Xiaomi от 13:12 авторизация успешна, после неё обмен останавливается на DISCOVERY. Отсутствие иконок — подтверждённое отличие от доноров, но поля optional, а причина отказа конкретной магнитолы этим ещё не доказана. Приёмник Carlinkit также не требует их обязательного наличия. Новая сборка требует проверки на той же магнитоле и нового журнала при повторении сбоя. Изменение тайм-аутов, отключение проверки сертификатов и исключения по модели авто не добавлялись.

Проверки: 1555/1555 модульных тестов; lint без ошибок (152 предупреждения). На Android 10–17 пройдены 53/53 сценария после отдельного повтора проверки двойного Back на API29 с неизменённым APK. Первоначальный сбой сохранён. В матрицу входят 24/24 независимых TLS/DISCOVERY-обмена через OpenSSL.

## English

Local test candidate, version code 100; unchanged DriveDeck 0.7.0 (356).

AA DISCOVERY now includes HSD PNG presentation icons at 32/64/128 pixels, matching the complete field set used by both investigated phone-side senders. The installation ID is stable across certificate changes. Phone presentation is separated from TLS identity selection, icons are cached, and Bluetooth bootstrap avoids image generation. Bounded negotiation-only diagnostics distinguish a written request, missing response, partial AAP frame and TLS decode failure.

Removed unreachable pre-Android-10 Wi-Fi code and unused resources/themes/strings. Added an independent OpenSSL receiver covering certificate verification, GCM/CBC, encrypted authorization and framing. The reported Xiaomi head unit's physical failure remains unconfirmed: optional icon fields and a strict fixture failure alone do not establish its root cause. A new vehicle log is required if the failure persists.
